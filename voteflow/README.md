# VoteFlow – Civic Education Simulation

A smart, interactive civic education platform designed to simplify the voting process and enhance civic literacy. The platform features **Mitra** (formerly Sahayak), an intelligent AI-powered assistant that guides users through every stage of the democratic cycle.

## 🚀 Overview
VoteFlow (Chunav Mitra) provides a high-fidelity, role-based simulation of a modern election environment. It allows users to step into the shoes of different stakeholders and understand the complexities of democracy from every angle.

## ✨ Key Features
- **Role-Based Simulation:** Experience democracy as a Voter, Candidate, Election Officer, or Journalist.
- **Mitra AI Assistant:** A smart, moving, and context-aware guide that helps users navigate the UI and provides real-time answers from a structured civic knowledge base.
- **Resource Documentation Center:** A comprehensive library of guides, articles, and toolkits on voting rights, election law, and media literacy.
- **Rush Prediction:** A visual analytics tool to help voters identify peak hours and optimize their polling station visits.
- **Cinematic UI:** A premium SaaS aesthetic with dark-mode styling, glassmorphism, and smooth Framer Motion animations.

## 🧠 Our Approach
- **Context-Aware Assistance:** Mitra tracks the user's current screen and selected role to provide personalized guidance.
- **Dataset-Driven Intelligence:** The platform's knowledge is entirely powered by a modular JSON dataset, allowing for easy updates and factual reliability.
- **Physical Navigation Guidance:** Mitra doesn't just talk; it physically moves across the screen to point out and highlight key UI elements using a golden pulse effect.

## 🛠 Tech Stack
- **Frontend:** React 19, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Tooling:** Vite, Google Antigravity

## 🧭 How It Works
1. **Authentication:** Secure login with voter verification sequence.
2. **Role Selection:** Choose your persona (e.g., First-Time Voter).
3. **Guided Simulation:** Mitra guides you through verification, registration, and ballot casting.
4. **Learning:** Explore the Documentation hub for deep-dives into election laws and disinformation spotting.

## ⚠️ Assumptions & Limitations
- **Simulated Data:** Scenarios and statistics are generated for educational purposes.
- **Simplified Law:** Complex legal protocols are simplified to ensure clarity for general users.

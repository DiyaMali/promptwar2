# 🚀 PromptWar2

🔗 GitHub Repository: https://github.com/DiyaMali/promptwar2


## 🧠 Project Overview

**PromptWar2** is a web-based AI-powered application designed to explore and enhance prompt-based interactions.  
The system is built to handle user inputs intelligently and return optimized, structured outputs using a scalable backend architecture.

The project is containerized using Docker and deployed on **Google Cloud Run** for scalable and serverless execution.

## 🎯 Chosen Vertical

### 💡 AI + Web Application + Cloud Deployment

This project falls under the **AI-powered web solutions** vertical, focusing on:

- Prompt processing logic
- Scalable deployment using cloud infrastructure
- Containerized application delivery using Docker
- Real-time interaction system

## ⚙️ Approach & Logic

The system is designed with a modular architecture:

### 1. Frontend Layer
- Handles user input and UI interaction
- Sends requests to backend API

### 2. Backend Layer
- Processes incoming prompts
- Applies logic to structure and optimize responses
- Handles routing and API requests

### 3. Container Layer (Docker)
- Entire application is containerized
- Ensures consistency across environments

### 4. Deployment Layer (Cloud Run)
- Deployed using Google Cloud Run
- Provides auto-scaling and serverless execution

🔄 How the Solution Works

1. User enters a prompt via the UI
2. Request is sent to backend server
3. Backend processes the prompt and applies logic rules
4. Response is generated and returned to frontend
5. Output is displayed to the user
